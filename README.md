# iOS 12 Cydia repo

Cydia source: https://dreyzedev.github.io/

Packages:

- **iOS 2 Lock Clock** - iOS 2 style lock screen clock tweak.
- **Telegram 10.0.3** - official Telegram build for iOS 11+ without Apple ID.

Telegram is built from https://github.com/TelegramMessenger/Telegram-iOS (unsigned build 26855).
